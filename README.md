# Daria — SMM Portfolio

A static, dependency-free portfolio designed as a Mac desktop.

The interface is bilingual (Ukrainian/English). It selects Ukrainian for
visitors in Ukraine using a country-level IP lookup, falls back to the browser
language, and remembers a visitor's manual language choice.

## Edit before publishing

1. Replace `hello@example.com` in `index.html`.
2. Replace the generic About copy if needed.
3. Add verified results, screenshots and links to each case study.

## Run locally

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Free hosting

The site is compatible with GitHub Pages, Cloudflare Pages and Netlify.
